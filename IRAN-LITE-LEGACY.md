# Iran Lite for older Android

This preview is based on v2rayNG 1.10.25 and its upstream Xray bindings v25.10.15. It targets Android 5.0 or newer. Pick armeabi-v7a for 32-bit ARM or arm64-v8a for 64-bit ARM. It uses a separate app ID so it can be tried alongside the current Iran Lite build.

Import your usual VLESS subscription and connect. The default Iran Lite preset routes the shared Iranian domains and IPs directly and sends ChatGPT through the proxy. To refresh rules, use the download button in Asset files, then disconnect and reconnect. The routing files are bundled for offline startup. APK builds are debug-signed previews. Android 5 runtime testing is pending.
